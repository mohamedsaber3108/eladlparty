# خريطة المحتوى الرسمي للموقع

تُستخدم هذه الخريطة عند إدخال المحتوى من لوحة الإدارة. المصدران المرجعيان هما «رؤية وأهداف الأمانة» و«الخطة الاستراتيجية والرؤية والهيكل التنظيمي الكامل - سبتمبر 2026». لا يُنشر اسم أو رقم أو موعد أو شراكة لم يرد في مصدر رسمي معتمد.

| المصدر الرسمي | المحتوى المستخرج | صفحة العرض |
|---|---|---|
| الرؤية | منصة وطنية تربط رواد الأعمال والمستثمرين والجامعات والقطاع الخاص والجهات الحكومية والشركاء الدوليين | `/about/vision` |
| الرسالة | تمكين الشباب والسيدات بالمهارات والتفكير الاقتصادي والبرامج والشراكات | `/about/vision` |
| أهداف السنة الأولى | الهيكل خلال شهرين، 6–10 برامج، 10 محافظات، 5 شراكات مؤسسية، قاعدة بيانات، حضور رقمي | `/about/objectives` و`/` |
| الهيكل التنظيمي | الأمين، أمين مساعد، مستشارون، مكتب الأمين، منسق عام، قطاعات عمل، أمانات المحافظات | `/about/structure` |
| الفئات المستهدفة | مدارس، جامعات وحديثو التخرج، السيدات، أصحاب المشروعات الصغيرة، مناطق أقل حظًا، المصريون بالخارج | `/programs`, `/join` |
| البرامج المقترحة | مدارس، جامعات، تحديات، حلقات تدريبية، تمكين السيدات، معسكرات، حاضنات مصغرة، قوافل، برامج رقمية، فعالية سنوية | `/programs`, `/initiatives`, `/events` |
| الحوارات الوطنية | مشاركون، شركاء، تحديات، توصيات، حلول مقترحة، ورقة سياسات | `/observatory`, `/observatory/policies` |
| الشراكات | جامعات، قطاع خاص، صناديق استثمار، حاضنات ومسرعات، شركات تقنية، منظمات | `/partnerships` |
| المعرفة | تقارير سنوية، أوراق سياسات، تقارير شركات ناشئة ومشروعات صغيرة واستثمار وذكاء اصطناعي | `/insights`, `/resources` |
| خارطة الطريق | تأسيس، إطلاق، توسع أول، تعميق، ذروة وتقييم | `/about/objectives` و`/insights/reports` |
| مؤشرات الأداء | محافظات مفعلة، برامج، مستفيدون، شراكات، وصول رقمي، تغطية إعلامية، تحويل عضوية | `/observatory`, `/admin` |

## قواعد إدخال المحتوى

1. كل برنامج أو فعالية أو فرصة جديدة: أضف `status`, `date`, `target audience`, `location`, `eligibility` وCTA فقط عندما تعتمدها الأمانة.
2. كل ورقة سياسات: ابدأ بحالة `draft` أو `قيد التشاور` إلى أن تعتمد للنشر.
3. لا تستخدم أسماء شاغلي المناصب في صفحة القيادة قبل تسليم قائمة رسمية معتمدة.
4. لا تعرض قياسات للمستفيدين أو نسب أثر قبل إدخالها من تقارير المتابعة.
5. أدخل لكل مادة نسخة عربية ونسخة إنجليزية منفصلتين على `locale=ar` و`locale=en`.
