# أمانة ريادة الأعمال المركزية — حزب العدل

موقع ثنائي اللغة مبني بـ Next/Vinext ومهيأ للنشر على Cloudflare Workers.

## ما يتضمنه

- بوابة عربية أولًا متعددة المسارات: الأخبار والتفاصيل، الفعاليات، البرامج، المبادرات، الفرص، المرصد، السياسات، التقارير، الموارد، الشراكات، الدعوات، الوسائط، الأسئلة الشائعة، وطرق المشاركة.
- Navigation responsive متعدد المستويات، بحث وفلاتر وترقيم وحالات تحميل/فراغ/خطأ ونماذج حقيقية.
- لوحة إدارة في `/admin` لإدارة المحتوى والفعاليات والبرامج والتقارير والوسائط وقاعدة معرفة المساعد والمستخدمين والمشاركات الواردة.
- APIs للمحتوى العام والبحث، الرسائل، المساعد، والإدارة المحمية بـ `ADMIN_TOKEN`.
- قاعدة D1 ومخطط Drizzle وترحيلات متسلسلة محفوظة في `drizzle/`.

## التشغيل

```bash
pnpm install
cp .dev.vars.example .dev.vars
pnpm build
pnpm start
```

ضع قيمة طويلة عشوائية لـ `ADMIN_TOKEN` في بيئة الإنتاج. لا تضعها في المستودع. طبّق ترحيلات Drizzle عند النشر لإنشاء جداول المحتوى والوسائط والمعرفة والمستخدمين والمشاركات.

## مسارات API

- `GET /api/content?type=&q=&slug=` — المحتوى المنشور والبحث والتفاصيل.
- `POST /api/submissions` — استقبال مقترحات ومشكلات الجمهور.
- `POST /api/chat` — إجابات موجهة عن الأمانة والمشاركة.
- `GET|POST /api/admin/content` — إدارة المحتوى باستخدام الترويسة `x-admin-token`.
- `GET|POST /api/admin/media|knowledge|users` — إدارة الوسائط ومعرفة المساعد والمستخدمين.
- `GET|PATCH /api/admin/submissions` — عرض المشاركات وتحديث حالتها.

> الشات بوت لا يولّد موقفًا سياسيًا؛ يجيب من قواعد المعلومات المعتمدة ويوجه الحالات غير المغطاة للفريق.
